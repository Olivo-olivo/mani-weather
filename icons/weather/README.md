# Weather artwork

Meteocons by Bas Milius, @meteocons/svg-static 0.1.0, flat style.
Source: https://github.com/basmilius/meteocons
Package: https://registry.npmjs.org/@meteocons/svg-static/-/svg-static-0.1.0.tgz

Rain strokes in rain, partly-cloudy-day-rain, partly-cloudy-night-rain and thunderstorms-rain have been recoloured from #0A5AD4 to turquoise #5EEAD4 for contrast on the dark page. Other SVGs are unmodified. MIT license is included in LICENSE.
Served locally and precached for offline use; no runtime CDN dependency.
